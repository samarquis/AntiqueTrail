## Product direction

Build a professional, public-facing Progressive Web App for antique shoppers.

The product combines:

- Antique-store discovery
- Public store ratings and reviews
- User-specific taste profiles
- Store recommendations based on personal preferences
- Store-hours-aware multi-stop trip planning
- One-stop-at-a-time navigation handoff to Waze or Google Maps
- Private saved finds, purchases, notes, trips, and collections
- Optional store-owner accounts and claimed listings

The original discovery work came from one household's antiquing habits, but the product must contain no personal data or household-specific assumptions. Personal preferences belong only inside each user's private account.
